# La Foire de Liège

Séquence pour iPad : on découvre la plus vieille fête foraine de Belgique, on répond à des questions puis on présente une attraction.

**Ouvrir l'application : https://ludo1104-rp.github.io/foire-liege/**

- **1. Je découvre** : un récit animé en 10 parties, avec une vidéo. Texte complet ou texte facile.
- **2. Je comprends** : 36 questions de lecture, 3 défis (6, 8 ou 10 questions).
- **3. Je présente** : une fiche guidée pour présenter une attraction à la classe.
- « Mes questions difficiles » et la fiche sont enregistrées sur l'appareil.
- Guide pour le professeur : [GUIDE-PROF.md](GUIDE-PROF.md).
- Fonctionne hors ligne : tout est dans `index.html`.

Version 1.0 — Application produite par IA à partir d'un document Internet (Wikipédia « Foire de Liège » et vidéo de Qu4tre – Liège Média). Des erreurs peuvent survenir.
Application développée par Claude AI sous la supervision de Ludo (@rprof_1).
